# CampusPe website rebuild

This is a multi-section responsive Next.js. It includes the campus-to-career hero, dashboard mockup, partner strip, opportunity feed, resume upload UI, student/recruiter sections, campus drive features, app mockups, support CTA, signup interaction, FAQ and footer.

## Run locally
Requires Node.js 20.9+ and npm.
```bash
npm install
npm run dev
```
Open http://localhost:3000.

Check production build:
```bash
npm run build
```
